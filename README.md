# JavaScript — Guia Interativo

Landing page educacional sobre JavaScript, criada com **HTML, CSS e JavaScript**.

## Funcionalidades
- Conteúdo sobre história, conceitos, benefícios e curiosidades do JavaScript
- Exemplos de código com destaque visual
- Navegação por seções e submenus interativos
- Layout adaptado para telas menores, navegação por teclado e redução de movimento
- Vídeo e imagens originais preservados

## Como visualizar
Abra `index.html` no navegador ou use uma extensão de servidor local no VS Code. O arquivo de entrada agora fica na **raiz do repositório**, adequado para publicação pelo GitHub Pages.

## Estrutura
```text
index.html
css/style.css
js/script.js
Trabalho conslusão/
  landingPage.html      # Versão original preservada
  *.png                 # Imagens originais
  *.mp4                 # Vídeo original
```

## Tecnologias
HTML5 · CSS3 · JavaScript · Font Awesome · Google Fonts

## Publicação
Em **Settings → Pages**, selecione **Deploy from a branch**, branch padrão e pasta **/(root)**. O endereço é disponibilizado pelo GitHub após a publicação.

## Créditos e fontes
Conteúdo educacional baseado em referências listadas na seção final da página, incluindo MDN e ECMA International. Verifique os termos de uso das mídias antes de reutilizá-las.

## Notas
A versão original permanece no diretório `Trabalho conslusão/`. A versão reorganizada remove a exibição pública do telefone pessoal. Não foi adicionado framework nem dependência de build.
